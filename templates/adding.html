What should the JSON look like?

The same layout as the app's recipe files: one recipe, a list of recipes, or {"recipes": [...]}. name and ingredients are needed; everything else is optional. Ingredients can also be plain lines like "200 g flour", and recipe JSON copied from a website works too.

{
  "name": "Taiyaki",
  "cuisine": "Japanese",
  "weight": 6,
  "link": "https://…",
  "ingredients": [
    {"quantity": "150", "measurement": "g", "name": "plain flour"},
    "1 tsp baking powder"
  ],
  "instructions": ["Mix the batter", "Cook in the mould"]
}
